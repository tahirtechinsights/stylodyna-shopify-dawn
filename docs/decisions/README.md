# Architectural Decision Records (ADRs)

This directory contains Architectural Decision Records (ADRs) for the StyloDyna Storefront. An ADR documents a significant technical or design choice, including its context, rationale, and consequences.

## Format & Workflow
Each ADR is authored using [`docs/templates/ADR-TEMPLATE.md`](file:///e:/StyloDyna/Store%20Website/Project/stylodyna-shopify-dawn/docs/templates/ADR-TEMPLATE.md) and assigned a sequential three-digit identifier (`ADR-001`, `ADR-002`, etc.).
