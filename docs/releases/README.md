# Release Management Architecture

This directory houses release records, version notes, and historical tags for the StyloDyna Shopify Storefront theme.

## Release Policy
1. **Production Releases (`main`)**: Production releases are tagged on `main` following semantic versioning (`v1.0.0`, `v1.1.0`, etc.).
2. **Release Notes**: Each production deployment must generate a release note using [`docs/templates/RELEASE-NOTES-TEMPLATE.md`](file:///e:/StyloDyna/Store%20Website/Project/stylodyna-shopify-dawn/docs/templates/RELEASE-NOTES-TEMPLATE.md) stored in `docs/releases/release-notes/`.

## Baseline Release
- **v1.0.0 (Official Baseline Release)**: Commit `ec19a48` (*StyloDyna official Release!*). Formally establishes StyloDyna as an independent custom Shopify theme.
