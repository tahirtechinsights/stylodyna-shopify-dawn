## Governance Rules & Anti-Corruption Protocols

1. **No Overwrite Policy**:
   Authoritative design-reference files are strictly **human-approved, read-only artifacts**. Antigravity must **NEVER** overwrite, recompress, convert, rename, replace from `.user_uploaded`, or automatically update manifest SHA-256 hashes for reference files.

2. **Explicit Human Versioning Rule**:
   When a design reference update is officially approved by the human operator, create a **NEW versioned file** (e.g., `whatsapp-hover-panel-ui-reference-v2.png`). Do not overwrite v1.

3. **Separation of Reference vs Actual Output**:
   - `docs/design-references/.../reference.png` = Approved human visual target
   - `docs/design-references/.../actual-preview.png` = Storefront output evidence
   These paths are permanently separate and must never share or overwrite each other.

4. **Visual Inspection Before Copying**:
   Never copy `.user_uploaded` assets based on file name or timestamp assumptions alone. Inspect format, magic bytes, pixel dimensions, and visual content first.
